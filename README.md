# Usage HUD

Claude Code · Codex 사용량과 맥 리소스를 항상 화면 최상단에 띄워두는 macOS 플로팅 HUD.

전체화면 앱 위에도 계속 보이고, 실행 중인 Claude Code 세션이 지금 뭘 하고 있는지 —
작업 중인지, 승인을 기다리는지, 멈췄는지 — 한눈에 보여줍니다.
(세션 목록은 Claude Code 전용입니다. Codex 는 사용량만 표시합니다.)

## 설치

**필요한 것은 Xcode Command Line Tools 하나뿐입니다.** 없으면 먼저 설치하세요:

```bash
xcode-select --install
```

레포를 받아 설치 스크립트를 실행합니다:

```bash
git clone <저장소 주소> usage-hud
cd usage-hud
./install.sh
```

끝입니다. 스크립트가 알아서 하는 일:

1. `~/Applications/UsageHUD/` 에 소스를 복사
2. `swiftc` 로 그 자리에서 앱을 빌드 — 남이 서명한 바이너리를 받는 게 아니라
   내 맥에서 컴파일하므로 Gatekeeper 차단이 없습니다
3. `~/.local/bin/hud` CLI 설치
4. 로그인 시 자동 실행 등록 (LaunchAgent)
5. Claude Code `statusLine` 훅 등록 — **이미 쓰는 설정이 있으면 건드리지 않습니다**
6. HUD 실행

빌드가 끝나면 화면 **우측 상단**에 HUD 가 떠 있습니다. 안 보이면 다른 모니터나
화면 밖에 있을 수 있으니 `hud restart` 로 위치를 초기화하세요.

`hud` 명령이 "command not found" 로 나오면 `PATH` 에 추가하세요:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

동작 확인:

```bash
hud now        # 현재 수치가 터미널에 출력되면 정상
```

업데이트는 `git pull && ./install.sh`, 제거는 `./uninstall.sh` 입니다.
제거해도 Claude 대화 기록은 건드리지 않습니다.

## 표시되는 값

| 행 | 출처 |
|---|---|
| **Claude** | 데스크톱 앱이 15분마다 기록하는 `plan-usage-history.json` (서버 실측) |
| **Codex** | `~/.codex/sessions/**` 롤아웃에 기록된 `rate_limits` (서버 실측) |
| **RAM** | `vm_stat` — 앱 + wired + 압축됨 (활성 상태 보기와 동일한 공식) |
| **Disk** | `df` |

### RAM 색에 대하여

macOS 는 남는 메모리를 캐시로 다 쓰므로 사용률 80~90%가 정상입니다. %로 색을 칠하면
늘 빨갛게 보여 정보가 없어집니다. 그래서 커널이 직접 계산하는
`kern.memorystatus_vm_pressure_level` 을 1차 신호로 씁니다 (1 정상 / 2 경고 / 4 위험).

보조 기준은 **스왑 절대량이 물리 메모리의 25%를 넘는지**입니다. `used/total` 비율은
쓰지 않습니다 — macOS 는 페이징이 줄면 스왑 파일도 함께 줄이기 때문에, 실제 사용량이
7.1GB 에서 3.2GB 로 절반 이하가 되어도 비율은 89%에서 81%로 거의 그대로입니다.
나아진 것과 나빠진 것을 구분하지 못합니다.

### Codex 값에 대하여

Codex 는 대화를 이어갈 때 **원래 롤아웃 파일에 덧붙입니다.** 6월에 시작한 스레드를
오늘 이어가면 그 6월 파일에 오늘 값이 들어갑니다. 반대로 새 세션은 아직 한도를 받기
전에 빈 롤아웃부터 만듭니다. 그래서 파일 이름이나 수정 시각으로 최신을 고르면 틀립니다.
HUD 는 후보 파일들을 훑어 **이벤트 타임스탬프가 가장 최근인 값**을 씁니다.

기록이 5시간 창보다 오래됐으면 숫자 대신 `만료` 로 표시합니다. 그 창은 이미 여러 번
리셋됐으므로 옛 퍼센트를 보여주면 거짓말이 됩니다.

### Claude 값에 대하여

**Anthropic 은 5시간 한도를 % 로만 알려줍니다.** 토큰이나 달러로는 공개하지 않고,
로컬에서 센 토큰을 % 로 환산할 방법도 없습니다. 그러니 서버가 준 값이 없으면
HUD 도 모릅니다.

값이 들어오는 경로는 둘뿐입니다:

| 사용 방식 | entrypoint | 한도 % |
|---|---|---|
| Claude 데스크톱 **챗** 앱 | — | ✅ `plan-usage-history.json` 에 주기적으로 기록 |
| 터미널에서 `claude` | `cli` | ✅ `statusLine` 훅이 받아옴 |
| 데스크톱 앱의 **Code 탭** | `claude-desktop` | ❌ |
| VS Code 확장 | `claude-vscode` | ❌ |

Claude Code 로만 작업하면 어느 쪽도 갱신되지 않습니다. 한도 % 를 보시려면
**둘 중 하나를 띄워 두세요.** 아무 일도 안 시켜도 됩니다.

#### 정확한 사용률 — `use_oauth_usage` (기본 꺼짐)

Anthropic 에는 사용률을 바로 주는 엔드포인트가 있습니다
(`api.anthropic.com/api/oauth/usage`). 이걸 켜면 **작업 방식과 무관하게 항상
정확한 값**이 나옵니다. Claude Code 로만 작업해도 됩니다.

```json
{ "use_oauth_usage": true }
```

**켜면 HUD 가 키체인(`Claude Code-credentials`)에서 OAuth 토큰을 읽어 그 요청에
씁니다.** 끄면 키체인을 열지도, 외부로 요청을 보내지도 않습니다 (기본값).
처음 켤 때 macOS 가 키체인 접근을 허용할지 한 번 물어봅니다.

토큰을 다루므로 다음을 지키고, **`tools/preflight.sh` 가 매 푸시마다 강제**합니다:

- 토큰은 메모리에만 둡니다. 캐시 파일(`.oauthusage.json`)에는 수치와 시각만
  들어갑니다
- 예외 메시지로 새지 않게 `_scrub()` 을 거칩니다. 이름만 비슷한 함수로 우회할
  수 없도록 호출형으로 검사합니다
- 통신·자격증명 접근은 `stats.py` 의 `OAUTH-BEGIN`~`OAUTH-END` 구간 안에서만
  허용하고, 그 바깥에 생기면 푸시가 막힙니다

검사가 실제로 잡아내는지는 일부러 위반을 넣어 확인했습니다 — 구간 밖 통신,
토큰 파일 기록, `_scrub` 우회 세 가지 모두 걸립니다.

서버에는 분당 한 번만 묻습니다(`OAUTH_TTL`). HUD 자체는 15초마다 갱신됩니다.

HUD 는 이 출처를 포함해 **가장 최신인 쪽**을 고르고, 상태를 세 가지로 표시합니다:

1. **실측** — 5분 이내의 서버 값
2. **실측 + 보정** — 같은 5시간 블록 안의 서버 값을 기준점으로 잡고, 그 뒤 로컬
   토큰 증가분만큼 이어붙임
3. **기준 없음** — 쓸 수 있는 기준점이 없음. **% 를 표시하지 않습니다.**
   비용·토큰·리셋 시각은 실측이므로 그대로 보여줍니다

**3번에서 추정치를 만들지 않는 이유.** 예전에는 과거 실측에서 역산한 천장으로
`~N%` 를 띄웠습니다. 2주치 샘플로 그 천장을 검증해보니 달러 기준 **35배**,
생토큰 기준 **186배** 흩어졌습니다 — 같은 1%p 를 쓰는 데 어떤 때는 $20,
어떤 때는 $486 이 들었습니다. 한도가 로컬에서 셀 수 있는 것과 다른 기준으로
매겨진다는 뜻이고, 데이터를 더 모아도 좁혀지지 않습니다. 실제로 이 추정이
**15% 를 93% 로** 표시한 적이 있습니다. 틀린 숫자보다 빈칸이 낫습니다.

**2번 보정에 건 두 가지 제한.** 보정은 `기준점% × (블록 전체 비용 ÷ 기준점까지의
비용)` 입니다. 분모가 작으면 지렛대가 폭주합니다 — 분모가 $17 이면 $17 쓸 때마다
11%p 씩 뜁니다. 그래서:

- 기준점이 **1시간보다 낡으면** 보정하지 않고 3번으로 떨어집니다
- 기준점까지의 비용이 블록 전체의 **절반 미만이면** 보정하지 않습니다.
  이 값이 곧 배율 상한이라, 보정은 기준점의 2배를 넘지 못합니다

`config.json` 의 `claude_5h_budget_usd` 로 천장을 직접 정하면 3번 상황에서도
`~N%` 를 보여줍니다. 자동 역산과 달리 그 숫자가 어디서 왔는지 본인이 아는
값이기 때문입니다.

`statusLine` 훅은 설치 시 자동 등록되지만, 이미 쓰고 있는 설정이 있으면 건드리지
않습니다.

## 세션 상태

**Claude Code 세션만 표시합니다. Codex 세션은 목록에 잡히지 않습니다.**

Claude Code 는 `~/.claude/sessions/<pid>.json` 에 실행 중인 세션 레지스트리를 남깁니다.
pid 와 세션 ID 가 들어 있어서 살아 있는 프로세스만 골라내고 트랜스크립트와 짝지을 수
있습니다. Codex 에는 대응하는 것이 없습니다 — 스레드 락 파일에 pid 가 없고, 롤아웃
파일도 턴마다 갱신되지 않아 아래 판별 기준을 적용할 수 없습니다.
Codex 는 사용량 게이지(5시간·주간 %)에만 쓰입니다.

| 표시 | 의미 | 판별 |
|---|---|---|
| ✖ 응답 없음 | 막힘 | 턴 중간 + 실행 중인 프로세스 없음 + 10분 경과 |
| ✖ API 오류 | API 재시도 반복 | 최근 5분 내 `api_error` 3회 이상 |
| ◉ 승인 대기? | 사람이 눌러야 함 | 턴 중간 + 프로세스 없음 + 90초~10분 |
| ▲ 지연 | 도구가 평소보다 오래 | 해당 도구 p99 의 3배 초과 |
| ● 작업 중 | 진행 중 | 90초 내 기록 갱신 |
| ◐ 실행 중 | 도구 정상 실행 | 자식 프로세스 살아 있음 |
| ○ 유휴 | 입력 대기 | 턴 종료 |

"지연" 임계값은 고정이 아닙니다. 최근 14일 트랜스크립트에서 도구별
`tool_use`→`tool_result` 간격을 재서 p99 를 학습하고, 하루 한 번 갱신합니다.
`AskUserQuestion` 처럼 원래 사람을 기다리는 도구는 임계가 자동으로 높게 잡힙니다.

## 마스코트

<img src="assets/mascot.png" width="128" alt="마스코트">

활성 세션 하나당 픽셀 캐릭터 하나가 HUD 위쪽 가장자리에 왼쪽부터 차례로 섭니다.
전부 유휴가 되면 사라지고, 작업이 다시 시작되면 돌아옵니다. 작은 화면에서도 나옵니다.

- 세션이 늘면 64pt → 32pt 로 줄고, 폭을 넘기면 `+N` 으로 접습니다
  (336pt 기준 64pt 4개, 32pt 9개)
- 어느 시트를 쓸지와 동작의 시작 지점은 pid 해시로 정합니다 — 겉보기엔
  무작위이면서 세션이 사는 동안 바뀌지 않습니다. 매번 난수를 뽑으면 갱신 주기마다
  캐릭터가 바뀌어 깜빡입니다
- 창은 클릭을 통과시키고(`ignoresMouseEvents`), 애니메이션 타이머는 보이는 동안만
  돕니다 (8fps)
- HUD 가 화면 꼭대기에 붙어 위쪽 자리가 없으면 HUD 아래로 내려갑니다

포함된 시트는 생성형 AI 로 만든 것입니다 — 라이선스는 [라이선스](#라이선스) 절을
보세요. 바꾸거나 더하려면 시트를 `assets/src/char-*.webp` 로 두고 전처리합니다:

```
swift tools/make-sprites.swift assets/src/char-a.webp assets/char-a.png 3x2
swift tools/make-sprites.swift assets/src/char-c.webp assets/char-c.png 4x2
```

전처리는 프레임별 가로·바닥 편차를 **바닥 중앙** 기준으로 맞춘 뒤 논리 128px 로
줄여 `assets/char-*.png` (가로 스트립, 높이 128) 를 만듭니다.

- **격자는 인자로 줍니다** (기본 `3x2`). 가로세로 비만으로는 `4x2` 와 `2x1` 을
  구별할 수 없어 자동 판별은 하지 않습니다
- **프레임 수는 시트마다 달라도 됩니다.** HUD 가 스트립 폭을 128 로 나눠
  알아냅니다. `assets/` 에 `char-*.png` 를 두면 코드를 고치지 않아도 후보에
  들어갑니다
- **칸 크기가 정수로 떨어지지 않아도 됩니다** (1774×887 의 `4x2` 는 칸이 443.5px).
  논리 픽셀의 한가운데를 집으므로 그림이 128 논리 격자에 올려져 있기만 하면 됩니다.
  칸이 512px 이면 `(x+0.5)×4 = 4x+2` 로 정수배 축소와 같은 좌표가 나옵니다
- **보간은 쓰지 않습니다.** 평균을 내면 픽셀아트 윤곽이 뭉개집니다. 그리기도
  `NSImageInterpolation.none` 입니다
- **알파는 128 기준으로 0 아니면 255 로 자릅니다.** 생성된 시트는 배경이 완전
  투명이 아니라 `a=16~31` 쯤의 옅은 안개가 깔려 있는 경우가 있는데, 그대로 두면
  캐릭터 뒤에 회색 사각형이 비치고 경계 판정도 안개를 내용으로 세어 프레임마다
  크기가 달라집니다

## 조작

- **드래그** 이동 (위치 저장됨)
- **우측 상단 `▾`** 또는 **우클릭 → 작은 화면** 으로 접기/펴기
- **빈 공간 우클릭** → 전체 메뉴 (새로고침 · 작은 화면 · 유휴 세션 정리 · 투명도)
- **세션 이름 우클릭** → 그 세션만 종료. 마우스를 올리면 대상 행이 밝아집니다
- **RAM 행 클릭** → 메모리를 많이 쓰는 앱 목록. 헬퍼 프로세스는 부모 앱으로 묶고,
  한 프로세스가 그룹의 절반을 넘으면 그 크기를 따로 적습니다 — 탭 30개가 조금씩 쓰는
  것과 확장 하나가 새는 것은 대응이 다릅니다
- **Disk 행 클릭** → 지우면 다시 생성되는 캐시 폴더들의 크기. `du` 가 느려서
  결과를 1시간 캐싱합니다 (최초 3초, 이후 0.4초)
- **우클릭 → 유휴 세션 정리** 로 오래된 세션을 한 번에 종료 (대화 기록은 보존)

세션을 종료하면 그 세션을 띄운 창에 `Claude Code process exited with code 143` 이
뜹니다. 143 은 `128 + 15`, 즉 SIGTERM 의 정상 종료 코드입니다. 세션은 서버에
보관되고(`Archive ... status=200`) 종료 훅도 정상 실행된 뒤 끝나므로 유실이 없습니다.
바깥에서 프로세스를 끝내면 그 창은 요청하지 않은 종료로 보기 때문에 나는 메시지이고,
`end_session` 제어 요청은 창과 프로세스 사이 stdio 채널로만 오가서 외부 도구가 쓸 수
없습니다. 이 메시지가 거슬리면 그 창에서 직접 세션을 닫으세요.
- **우클릭 → 투명도** 100~40%

## 동작 방식

15초마다 `stats.py` 를 실행해 로컬 파일만 읽습니다 (약 0.2초).

- `~/Library/Application Support/Claude/plan-usage-history.json` — Claude 실제 사용률
- `~/.claude/projects/**/*.jsonl` — 토큰 사용량, 세션 상태, 세션 제목
- `~/.claude/sessions/*.json` — 실행 중인 세션 목록
- `~/.codex/sessions/**/*.jsonl` — Codex 한도
- `vm_stat`, `df`, `ps`, `pgrep`

### 개인정보

**네트워크 요청이 전혀 없습니다.** 인증 정보(Keychain, `auth.json`, OAuth 토큰)에
접근하지 않고, 어떤 데이터도 기기 밖으로 나가지 않습니다.
실행하는 외부 명령은 `df`, `ps`, `pgrep`, `sysctl`, `vm_stat` 뿐이며 모두 읽기 전용입니다.

대화 트랜스크립트를 읽긴 하지만 **메타데이터만** 꺼냅니다 — 타임스탬프, 토큰 수,
도구 이름, 세션 제목, 진행 상태. 대화 본문은 파싱하지 않습니다.

디스크에 남기는 캐시는 숫자와 도구 이름뿐입니다:

| 파일 | 내용 |
|---|---|
| `.ceiling.json` | 5시간 한도 추정 천장 (숫자) |
| `.toolstats.json` | 도구별 p99 소요 시간 (도구 이름 + 초) |
| `.diskscan.json` | 캐시 폴더 경로와 크기 |
| `.ratelimits.json` | 사용률 %, 리셋 시각, 세션 ID |

**다만 세션 제목은 화면에 계속 표시됩니다.** 화면 공유나 발표 중에는 프로젝트명이
노출될 수 있으니, 작은 화면 모드(`▾`)로 접거나 `config.json` 에서
`prefer_custom_title` 을 `false` 로 두면 짧은 자동 이름만 보입니다.

- macOS 13 이상
- Xcode Command Line Tools (`xcode-select --install`)
- Python 3.9 이상 — macOS 기본 제공분으로 충분

Codex 를 안 쓰면 해당 행은 "데이터 없음" 으로 표시되고 나머지는 정상 동작합니다.
